# Internationalisation

Le front utilise Vue I18n en mode Composition API. Le français (`fr`) est la langue
initiale et la langue de repli. L’anglais (`en`) est aussi disponible.

- Configuration : `apps/web/src/i18n/index.ts`.
- Traductions : `apps/web/src/i18n/locales/fr.ts` et `en.ts`.
- Utilisation dans les composants : `const { t } = useI18n({ useScope: 'global' })`,
  puis `t('app.description')` dans le template.
- Changement de langue : importer `setLocale` depuis le module i18n et appeler
  `setLocale('en')` ou `setLocale('fr')`.
- L’attribut `lang` du document et le titre de page suivent la langue sélectionnée.

Ajouter les mêmes clés à tous les fichiers de langue. Le français définit le schéma
et `satisfies typeof fr` vérifie la structure de la traduction anglaise.
Pour ajouter une langue, créer son fichier, l’importer et l’enregistrer dans
`supportedLocales` et `messages`.

Le sélecteur de langue, la mémorisation du choix et la traduction des données du CV
seront définis lors du développement des fonctionnalités. Le backend n’a pas besoin
d’une bibliothèque de traduction à ce stade.

Documentation : https://vue-i18n.intlify.dev/guide/advanced/composition
