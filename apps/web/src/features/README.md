# Fonctionnalités

Créer les dossiers `cv`, `auth` et `linkedin` quand leur développement commence.
Chaque fonctionnalité regroupe ses composants, appels API, types, composables et stores.
Créer seulement les sous-dossiers nécessaires. Aucun code métier pour le moment.

Exemple futur : `cv/components/CvPreview.vue`, `cv/api.ts`, `cv/types.ts`,
`cv/stores/cv.ts`. Les pages publiques et administrateur réutiliseront le même module CV.
